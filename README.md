# Поделись теплом — divan.ru × «Антон тут рядом»

Исходный интерактивный веб-прототип новогодней открытки на двух согласуемых KV. Третий вариант добавляется позже.

## Что работает
- приветствие и переход к выбору пожелания;
- два пожелания, каждому соответствует оригинальный квадратный KV;
- экспорт квадратной открытки 2048 × 2048 в PNG;
- системная отправка / копирование персональной ссылки после размещения на HTTPS;
- отдельное состояние при открытии ссылки `?wish=calm` или `?wish=close`;
- ссылки на коллекцию и страницу поддержки фонда.

## Запуск
Откройте `index.html` в браузере. Для корректной проверки ссылок и загрузки картинок используйте локальный HTTP-сервер (например, `python3 -m http.server 8000`), затем `http://localhost:8000`.

## Публикация
Статический сайт: подходит для GitHub Pages или другого HTTPS-хостинга. Для GitHub Pages выберите *Settings → Pages → Deploy from a branch → main / root*, если возможности аккаунта позволяют публикацию. После публикации персональные ссылки будут указывать на опубликованный URL.

## Что ещё предстоит
- третий KV + третье пожелание;
- арт-дирекшн, тексты, финальная типографика и логотипы после согласования;
- более точные индивидуальные превью для мессенджеров (потребуется серверная логика);
- браузерное и мобильное финальное тестирование после деплоя.

## Важно
Это демо-версия, не готовая публичная благотворительная кампания. Не публикуйте в открытом доступе без утверждения правообладателями изображений, формулировок и фирменных элементов. Шрифтовые файлы Booklet Sans не включены; используются только локально установленные шрифты или системные замены.
